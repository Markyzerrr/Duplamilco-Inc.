# Duplamilco website draft

A responsive static company website with an editable product-category catalog, search/filter controls, mobile navigation, and subtle scroll-reveal motion.

## Preview locally

Open `index.html` in a modern browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — page content and metadata
- `styles.css` — layout, responsive styling, and animation
- `script.js` — mobile navigation, product filtering/search, and reveal effects

## Before publishing
1. Replace the temporary typographic D mark with the official Duplamilco logo and apply official brand colors.
2. Confirm the actual product range and edit the four draft category cards in `index.html`.
3. Add verified store address, phone, email, opening hours, and any delivery/service details.
4. Add real product and store photographs if available.
5. Connect a form or e-commerce platform if you want customers to place orders and pay online. This draft is a catalog/inquiry website, not a checkout/payment system.

The only contact destination included is the Facebook page supplied for the project: https://www.facebook.com/duplamilco/.
